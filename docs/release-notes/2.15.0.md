    Other Hummingbot repositories such as [Hummingbot-API](https://github.com/hummingbot/hummingbot-api), [Hummingbot MCP](https://github.com/hummingbot/mcp), [Hummingbot Skills](https://github.com/hummingbot/skills), [Quants-Lab](https://github.com/hummingbot/quant-lab), and [Condor](https://github.com/hummingbot/condor) follow a continuous deployment model without fixed version releases. Use the `main` branch for these repositories.

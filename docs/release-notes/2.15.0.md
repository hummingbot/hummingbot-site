### 🔒 Tailscale Security

Condor and Hummingbot API now support [Tailscale](https://tailscale.com) for private, encrypted access between your devices. Connect over a tailnet instead of exposing port 8000 to the public internet—keeping order placement, balances, and bot control behind a VPN only your machines can reach.

See the [Tailscale guide](/hummingbot-api/tailscale/) for setup instructions, or read [Securing Condor and Hummingbot API with Tailscale](/blog/posts/securing-condor-and-hummingbot-api-with-tailscale/) for a full security walkthrough.

**PR:** [condor #92](https://github.com/hummingbot/condor/pull/92) | [hummingbot-api #156](https://github.com/hummingbot/hummingbot-api/pull/156)

### 🔗 Chainstack RPC Provider

Gateway adds [Chainstack](https://chainstack.com/) as a cross-chain RPC provider for both Solana and EVM networks—the first provider to use API-driven node discovery instead of URL templating. Route DEX traffic through deployed Chainstack nodes for lower latency, higher availability, and more reliable swap execution.

See [RPC Providers](/gateway/rpc/) for setup instructions.

**PR:** [#623](https://github.com/hummingbot/gateway/pull/623) | **Thanks to [smypmsa](https://github.com/smypmsa)! 🙏**

### 🤖 OpenRouter LLM Support

Condor now supports [OpenRouter](https://openrouter.ai/) as an LLM provider for `/agent`, giving you access to a large catalog of models through a single API key. OpenRouter also offers **free models** in the picker—select one with $0 pricing to use `/agent` without being charged.

**How to use:**

1. Create an API key at [openrouter.ai/keys](https://openrouter.ai/keys)
2. Add `OPENROUTER_API_KEY=sk-or-...` to your Condor `.env` file and restart the bot
3. In Telegram, run `/agent` → **Change LLM** → **OpenRouter — Pick Model** and select from the live catalog (free models show $0 pricing)

You can also choose **Enter model manually** and send an OpenRouter slug (for example `anthropic/claude-sonnet-4-5`, or `openrouter/free` for OpenRouter's free model router) if you already know which model you want.

**PR:** [#82](https://github.com/hummingbot/condor/pull/82)

### 📡 MQTT Bridge Migration

Migrated the remote MQTT bridge from `commlib-py` to `aiomqtt`, replacing paho's uncatchable disconnect errors with catchable reconnect logic on the event loop. Bots now recover automatically when the Hummingbot API broker restarts, without the degraded-performance issues seen on reconnect.

**PR:** [#8293](https://github.com/hummingbot/hummingbot/pull/8293)
